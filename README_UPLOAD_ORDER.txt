Порядок публикации обновления HORDE:

1. Сначала загрузить большие архивы сборки в GitHub Release `minecraft`:
   - HORDE-pack.zip
   - HORDE-pack-<base>.zip, если менялась базовая версия.

2. Затем положить актуальный лаунчер в корень сайта:
   - HORDE.exe

3. Последним обновить update.json:
   - в GitHub Release;
   - в корне сайта.

Важно: кнопки скачивания на сайте ведут на https://hordeminecraft.ru/HORDE.exe.
GitHub Release остаётся запасным зеркалом для лаунчера и основным местом для больших pack-архивов.
